# Requerimientos del sistema

## Requerimientos funcionales

RF-01. El sistema deberá permitir iniciar sesión.

RF-02. El sistema deberá permitir gestionar usuarios.

RF-03. El sistema deberá permitir registrar documentos.

RF-04. El sistema deberá permitir consultar información.

RF-05. El sistema deberá permitir generar reportes.

## Requerimientos no funcionales

RNF-01. El sistema deberá utilizar autenticación.

RNF-02. El sistema deberá controlar los permisos según el rol.

RNF-03. El sistema deberá ser responsive.

RNF-04. La información deberá almacenarse de forma estructurada.
