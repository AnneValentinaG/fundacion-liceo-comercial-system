# Arquitectura general del sistema

## 1. Sitio público

WordPress + Elementor alojado en Hostinger.

## 2. Aplicación privada

Django para las funcionalidades administrativas.

## 3. Base de datos

PostgreSQL.

## 4. Integración

El sitio público y la aplicación privada funcionarán como componentes independientes, con posibilidad de comunicación mediante API cuando sea necesario.
